# Evidence — 1.3.2: Out-of-band verifier used only once

## Summary

The verification code record is deleted from the database immediately upon
successful verification, making it impossible to reuse. Any previous codes for
the same user are also deleted when a new code is issued.

---

## Single-use enforcement — deleted on successful verification

File: `backend/core/views/auth_views.py` — `verify_code_view` function

```python
verification = SMSVerification.objects(userId=user_id, code=code) \
    .order_by("-created_at").first()

if not verification:
    increment_verify_attempt(verify_record)
    return JsonResponse({"error": "Invalid verification code"}, status=400)

# ... expiry check ...

# Delete the code immediately after successful validation
user = User.objects.get(pk=user_id)
verification.delete()            # <-- single-use: code removed from DB
reset_verify_attempts(user_id)

# Proceed to issue JWT tokens
refresh = RefreshToken()
...
```

## Previous codes invalidated on re-send

File: `backend/core/views/auth_views.py` — `send_verification_code` function

```python
# Delete any previous codes for this user so only the latest is valid
# and so that a double-submit cannot cause two active codes to coexist.
SMSVerification.objects(userId=user_id).delete()
SMSVerification(userId=user_id, code=code, expires_at=expires_at).save()
```

At most one active code exists per user at any time.
