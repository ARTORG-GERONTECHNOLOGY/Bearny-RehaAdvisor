# Evidence — 5.1.6: Protection against XPath/XML injection

## Summary

The application does not parse any XML data from user input. There is no
XPath query construction in the codebase. All data storage uses MongoDB
(document store via MongoEngine ORM) and SQLite (Django ORM) — neither uses
XML or XPath.

---

## Verification — no XML parsing of user input

```
$ grep -rn "xml\|xpath\|lxml\|etree\|minidom\|ElementTree" \
    backend/core/views/ | grep -v "test\|__pycache__\|#"
(no output)
```

## Data sources

| Source | Format | Parser |
|---|---|---|
| API requests | JSON | `json.loads()` |
| File uploads | xlsx/mp4/mp3/pdf/jpg/png | openpyxl / binary storage |
| REDCap API | JSON | `response.json()` |
| Fitbit/Google Health API | JSON | `response.json()` |
| MongoDB | BSON | MongoEngine ORM |

No XML is received from or sent to users.
