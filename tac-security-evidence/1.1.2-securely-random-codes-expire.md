# Evidence — 1.1.2: System-generated codes securely random and expire after short period

## Summary

The 2FA email verification code is generated using Python's `secrets` module
(cryptographically secure RNG), expires after **5 minutes**, and is deleted from
the database immediately after use so it cannot be replayed.

---

## Code generation — cryptographically secure

File: `backend/core/views/auth_views.py` (line 998)

```python
import secrets
import string

def generate_code(length=6):
    return "".join(secrets.choice(string.digits) for _ in range(length))
```

`secrets.choice` is backed by the OS CSPRNG (`os.urandom` / `getrandom(2)`).
The previous `random.choices` call (non-cryptographic) was replaced with
`secrets.choice` as part of the CASA AL1 remediation.

---

## Expiry — 5 minutes

File: `backend/core/views/auth_views.py` — `send_verification_code` function

```python
code = generate_code()
expires_at = timezone.now() + timedelta(minutes=5)

# Delete any previous codes so only the latest is valid
SMSVerification.objects(userId=user_id).delete()
SMSVerification(userId=user_id, code=code, expires_at=expires_at).save()
```

---

## Expiry enforcement at verification time

File: `backend/core/views/auth_views.py` — `verify_code_view` function

```python
expires_at_utc = expires_at.astimezone(dt_timezone.utc)
now_utc = timezone.now().astimezone(dt_timezone.utc)

if expires_at_utc < now_utc:
    verification.delete()
    return JsonResponse({"error": "Verification code expired"}, status=400)
```

Expired codes are deleted at check time and the user receives HTTP 400.
