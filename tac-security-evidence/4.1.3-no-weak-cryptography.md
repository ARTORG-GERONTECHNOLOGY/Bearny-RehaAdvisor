## Summary

The cipher suite configuration explicitly lists only AEAD ciphers with

## TLS cipher suite — all AEAD + forward secret

```nginx
ssl_ciphers
  ECDHE-ECDSA-AES128-GCM-SHA256:
  ECDHE-RSA-AES128-GCM-SHA256:
  ECDHE-ECDSA-AES256-GCM-SHA384:
  ECDHE-RSA-AES256-GCM-SHA384:
  ECDHE-ECDSA-CHACHA20-POLY1305:
  ECDHE-RSA-CHACHA20-POLY1305;
```

All ciphers are:
- GCM or ChaCha20-Poly1305 (AEAD — authenticated encryption)
- ECDHE key exchange (forward secrecy)
- AES-128/256 or ChaCha20 (no DES, RC4, or export-grade)

## OAuth token encryption — Fernet (AES-128-CBC + HMAC-SHA256)

File: `backend/core/encrypted_field.py`

```python
from cryptography.fernet import Fernet

class EncryptedStringField(StringField):
    def to_mongo(self, value):
        return _fernet().encrypt(value.encode()).decode()   # AES-128-CBC + HMAC-SHA256

    def to_python(self, value):
        return _fernet().decrypt(value.encode()).decode()   # verifies HMAC before decrypt
```

Fernet is an AEAD construction — it authenticates the ciphertext before
decrypting, preventing Padding Oracle attacks on stored tokens.
