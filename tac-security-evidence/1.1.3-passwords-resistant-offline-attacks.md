# Evidence — 1.1.3: Passwords stored resistant to offline attacks

## Summary

All user passwords are stored as **PBKDF2-SHA256** hashes with **870,000 iterations**
(Django 4.x default). Passwords are never stored in plaintext.

---

## Password storage in the application

File: `backend/core/views/user_views.py`

```python
from django.contrib.auth.hashers import check_password, make_password

# On password change:
user.pwdhash = make_password(new_password)
user.save()
```

File: `backend/core/views/auth_views.py`

```python
# On password reset:
user.pwdhash = make_password(new_password)
user.save()
```

`make_password()` uses Django's configured password hasher — PBKDF2-SHA256
with 870,000 iterations — and generates a random salt for every hash.

## Password strength requirements

File: `backend/core/views/user_views.py` — `change_password` function

```python
if (
    len(new_password) < 8
    or not re.search(r"[A-Z]", new_password)
    or not re.search(r"[a-z]", new_password)
    or not re.search(r"[0-9]", new_password)
    or not re.search(r"[!@#$%^&*(),.?\":{}|<>]", new_password)
):
    return JsonResponse(
        {"error": "Weak password: must contain upper, lower, number, special char, and 8+ chars"},
        status=400,
    )
```

Minimum requirements: 8 characters, uppercase, lowercase, digit, special character.
