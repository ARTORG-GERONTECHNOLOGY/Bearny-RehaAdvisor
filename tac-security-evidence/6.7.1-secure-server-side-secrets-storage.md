# Evidence — 6.7.1: Securely store access tokens, API keys, and server-side secrets

## Summary

All server-side secrets are stored in environment variables loaded from a
`.env.prod` file (not committed to version control). OAuth access and refresh
tokens are encrypted at rest in MongoDB using Fernet (AES-128-CBC + HMAC-SHA256).
The encryption key is itself stored as an environment variable.

---

## OAuth tokens encrypted at rest in MongoDB

File: `backend/core/models.py`

```python
class FitbitUserToken(Document):
    access_token  = EncryptedStringField(required=True, max_length=4096)
    refresh_token = EncryptedStringField(required=True, max_length=4096)

class GoogleHealthUserToken(Document):
    access_token  = EncryptedStringField(required=True, max_length=4096)
    refresh_token = EncryptedStringField(required=True, max_length=4096)
```

File: `backend/core/encrypted_field.py`

```python
from cryptography.fernet import Fernet

class EncryptedStringField(StringField):
    def to_mongo(self, value):
        return _fernet().encrypt(value.encode()).decode()   # write encrypted

    def to_python(self, value):
        return _fernet().decrypt(value.encode()).decode()   # read decrypted
```
