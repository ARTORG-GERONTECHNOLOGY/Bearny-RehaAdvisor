# Evidence — 3.1.1: Least privilege access control on trusted service layer

## Summary

Every API endpoint is protected by `JWTAuthMiddleware` (authentication) and
per-view role checks (authorisation). Admin-only endpoints use a dedicated
`IsAdmin` permission class. Therapist-scoped endpoints verify clinic
membership before returning patient data.

---

## Authentication layer — JWTAuthMiddleware

File: `backend/core/middleware.py`

All `/api/` routes (except a defined public allowlist) require a valid JWT.
Unauthenticated requests receive HTTP 401.

## Role-based permission class

File: `backend/core/permissions.py`

```python
class IsAdmin(BasePermission):
    """Allow access only to active users with role="Admin"."""
    message = "Admin role required."

    def has_permission(self, request, view):
        if not getattr(request.user, "is_authenticated", False):
            return False
        try:
            user = User.objects.get(pk=ObjectId(request.user.id))
            return user.role == "Admin" and user.isActive
        except Exception:
            return False
```

Applied to all admin endpoints:

```python
# backend/core/views/therapist_access_views.py
@api_view(["GET", "POST", "PUT"])
@permission_classes([IsAdmin])
def manage_therapist_access(request, ...):
    ...

# backend/core/views/admin_intervention_views.py
@api_view(["POST"])
@permission_classes([IsAdmin])
def import_interventions(request):
    ...
```

## Therapist scope — clinic ownership check

File: `backend/core/views/patient_views.py`

```python
# IDOR guard: allow the patient themselves or a therapist in the same clinic.
caller_therapist = get_therapist_for_user(request.user)
patient_clinic = getattr(patient, "clinic", None)
if not caller_therapist or patient_clinic not in (caller_therapist.clinics or []):
    return JsonResponse(
        {"error": "You are not authorised to access this patient's data."},
        status=403
    )
```

A therapist can only access patients in clinics they are assigned to —
not all patients in the system.
