# Evidence — 2.3.4: Stateless tokens use digital signatures and countermeasures against tampering/replay/null cipher

## Summary

JWTs are signed with HS256 (HMAC-SHA256). The algorithm is declared
explicitly — no algorithm negotiation is permitted. The middleware validates
signature, expiry, JTI denylist, and per-user valid-from timestamp on every
request.

---

## Explicit algorithm declaration

File: `backend/api/settings/base.py`

```python
SIMPLE_JWT = {
    "ALGORITHM": "HS256",    # ← explicit; no "none" or algorithm negotiation
    "ACCESS_TOKEN_LIFETIME":  timedelta(minutes=5),
    "REFRESH_TOKEN_LIFETIME": timedelta(days=1),
    ...
}
```

Explicitly setting `ALGORITHM` prevents the "none" algorithm attack: if a
client submits a JWT with `alg: none`, simplejwt will reject it because the
configured algorithm is HS256, not none.

---

## Token validation in JWTAuthMiddleware

File: `backend/core/middleware.py`

```python
try:
    token = AccessToken(token_str)     # verifies signature + expiry
except (TokenError, Exception):
    return JsonResponse({"detail": "Given token is not valid or has expired."}, status=401)

# Check per-JTI denylist (replay protection — set on logout)
jti = token.payload.get("jti", "")
if jti and is_jti_revoked(jti):
    return JsonResponse({"detail": "Token has been revoked."}, status=401)

# Check per-user valid_from (set on password change — all pre-change tokens invalid)
user_id = str(token.payload.get("user_id", ""))
if user_id:
    valid_from = get_user_valid_from(user_id)
    iat = int(token.payload.get("iat", 0))
    if valid_from and iat < valid_from:
        return JsonResponse({"detail": "Token has been invalidated. Please log in again."}, status=401)
```

| Protection | Mechanism |
|---|---|
| Tampering | HS256 signature check — any modified payload → invalid signature → 401 |
| Null cipher | Explicit `ALGORITHM: HS256` — "none" alg is rejected |
| Replay after logout | Per-JTI Redis denylist |
| Replay after password change | Per-user `valid_from` epoch in Redis |
| Expiry | `exp` claim validated by simplejwt `AccessToken()` |
