# Evidence — 2.3.2: Cookie-based session tokens have the 'HttpOnly' attribute set

## Summary

Both auth cookies are set with `httponly=True` unconditionally — the value
is never derived from a setting and cannot be overridden.

---

## Code

File: `backend/core/views/auth_views.py` — `_set_auth_cookies`

```python
response.set_cookie(
    "access_token",
    access_token,
    httponly=True,     # ← HttpOnly always set
    secure=secure,
    samesite="Strict",
    max_age=300,
)
response.set_cookie(
    "refresh_token",
    refresh_token,
    httponly=True,     # ← HttpOnly always set
    secure=secure,
    samesite="Strict",
    max_age=86400,
)
```

The `HttpOnly` flag prevents JavaScript from reading the token via
`document.cookie`, mitigating token theft through XSS.

---

## Production header (observed)

```
Set-Cookie: access_token=<jwt>; HttpOnly; Path=/; SameSite=Strict; Secure; Max-Age=300
Set-Cookie: refresh_token=<jwt>; HttpOnly; Path=/; SameSite=Strict; Secure; Max-Age=86400
```
