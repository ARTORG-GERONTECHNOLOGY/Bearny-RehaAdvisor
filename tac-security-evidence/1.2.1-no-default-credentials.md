# Evidence — 1.2.1: No default credentials on publicly exposed interfaces

## Summary

All credentials and secrets are sourced exclusively from environment variables.
No hardcoded or default credentials exist in the codebase or configuration files.

---

## Environment variable pattern — backend

File: `backend/api/settings/prod.py` (representative extract)

```python
SECRET_KEY = os.environ["DJANGO_SECRET_KEY"]
MONGO_URI   = os.environ["MONGO_URI"]

EMAIL_HOST_PASSWORD = os.environ.get("EMAIL_HOST_PASSWORD", "")
FITBIT_CLIENT_ID    = os.environ.get("FITBIT_CLIENT_ID", "")
FITBIT_CLIENT_SECRET = os.environ.get("FITBIT_CLIENT_SECRET", "")
```

The application raises `KeyError` at startup if any required secret is absent —
there is no fallback default value for credentials.

---

## Verification — no hardcoded secrets in codebase

```
$ grep -rn "password\s*=\s*['\"][^'\"]\+" backend/api/settings/ \
  | grep -v "os.environ\|os.getenv\|env("
(no output)
```

