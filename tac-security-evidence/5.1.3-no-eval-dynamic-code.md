## React JSX — automatic output escaping

React escapes all dynamic values rendered via JSX by default. A variable like
`{userInput}` is HTML-escaped before being inserted into the DOM.

The single use of `dangerouslySetInnerHTML` in the codebase
(`frontend/src/components/ui/chart.tsx`) injects only CSS custom property
declarations derived from hardcoded chart color configuration — not from any
user-supplied data:

```tsx
// Only chart theme colors (hex values from config) — no user input
dangerouslySetInnerHTML={{
  __html: Object.entries(THEMES).map(([theme, prefix]) =>
    `${prefix} [data-chart=${id}] { --color-${key}: ${color}; }`
  ).join('\n')
}}
```
