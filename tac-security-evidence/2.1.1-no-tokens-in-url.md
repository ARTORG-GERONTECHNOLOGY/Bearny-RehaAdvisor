# Evidence — 2.1.1: No passwords or session tokens in URL parameters

## Summary

JWT tokens are transmitted exclusively via **HttpOnly cookies**. No token is
ever placed in a URL query string, a redirect parameter, or a page body.
The API also accepts tokens via the `Authorization: Bearer` header for
programmatic clients — never via URL parameters.

---

## Cookie configuration — HttpOnly, Secure, SameSite=Strict

File: `backend/core/views/auth_views.py` — `_set_auth_cookies` function

```python
def _set_auth_cookies(response, access_token: str, refresh_token: str) -> None:
    secure = not getattr(_django_settings, "DEBUG", False)   # True in production

    response.set_cookie(
        "access_token",
        access_token,
        httponly=True,        # not readable by JavaScript
        secure=secure,        # HTTPS-only in production
        samesite="Strict",    # no cross-site sending
        max_age=300,          # 5 minutes — matches JWT ACCESS_TOKEN_LIFETIME
    )
    response.set_cookie(
        "refresh_token",
        refresh_token,
        httponly=True,
        secure=secure,
        samesite="Strict",
        max_age=86400,        # 1 day — matches JWT REFRESH_TOKEN_LIFETIME
    )
```

Tokens are cleared on logout:

```python
def _clear_auth_cookies(response) -> None:
    response.delete_cookie("access_token", samesite="Strict")
    response.delete_cookie("refresh_token", samesite="Strict")
```
