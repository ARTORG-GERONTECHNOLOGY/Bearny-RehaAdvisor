# Evidence — 3.1.6: Directory browsing disabled

## Summary

Neither the gateway nginx nor the inner application nginx has `autoindex on`.
The nginx default is `autoindex off` and no configuration in this stack
overrides it.

---

## Verification — no autoindex directive found

```
$ grep -rn "autoindex" nginx/
(no output)
```

Both nginx config files were searched:
- `nginx/gateway.nginx.conf`
- `nginx/conf/prod.reha-advisor.nginx.conf`

No `autoindex on` directive exists anywhere in the stack.

---

## Static file serving

The React SPA build is served by nginx as a static root with explicit
`try_files $uri /index.html` — only files in the build output directory
are accessible, and listing is not enabled.

File: `nginx/conf/prod.reha-advisor.nginx.conf`

```nginx
location / {
    root /app/dist;
    try_files $uri /index.html;
}
```

Requests for non-existent paths fall through to `index.html` (SPA routing),
not to a directory listing.
