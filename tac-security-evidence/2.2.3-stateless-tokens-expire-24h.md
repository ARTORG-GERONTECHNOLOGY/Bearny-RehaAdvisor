# Evidence — 2.2.3: Non-revocable stateless tokens expire within 24 hours

## Summary

- **Access token** lifetime: **5 minutes**
- **Refresh token** lifetime: **1 day (24 hours)**

Both are configured in `SIMPLE_JWT` settings and enforced by the
`rest_framework_simplejwt` library on every token validation.

---

## Settings

File: `backend/api/settings/base.py`

```python
from datetime import timedelta

SIMPLE_JWT = {
    "ACCESS_TOKEN_LIFETIME":  timedelta(minutes=5),   # 300 seconds
    "REFRESH_TOKEN_LIFETIME": timedelta(days=1),       # 86400 seconds — max 24 h
    "ROTATE_REFRESH_TOKENS":  True,
    "BLACKLIST_AFTER_ROTATION": True,
    "ALGORITHM": "HS256",
}
```

---

## Cookie `max_age` mirrors token lifetimes

File: `backend/core/views/auth_views.py`

```python
response.set_cookie(
    "access_token", access_token,
    httponly=True, secure=secure, samesite="Strict",
    max_age=300,    # 5 minutes — matches ACCESS_TOKEN_LIFETIME
)
response.set_cookie(
    "refresh_token", refresh_token,
    httponly=True, secure=secure, samesite="Strict",
    max_age=86400,  # 1 day — matches REFRESH_TOKEN_LIFETIME
)
```

The browser discards the cookies at expiry, and the tokens themselves
contain a `exp` claim verified cryptographically on every request.
